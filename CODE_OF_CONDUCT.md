# Code of Conduct

## Our standards

This project aims to be a respectful, constructive, and welcoming place for
people to collaborate. Be considerate, discuss ideas rather than attacking
people, accept good-faith feedback, and avoid harassment, discrimination,
threats, doxxing, or intentionally disruptive behavior.

## Scope

These expectations apply in repository issues, pull requests, discussions,
code review, and other project spaces where someone is representing the project.

## Enforcement

Project maintainers may edit, hide, reject, or remove contributions and may
limit participation when behavior violates these standards. Serious or repeated
incidents may result in a permanent ban from project spaces.

## Reporting

For conduct concerns, contact the maintainers privately through the repository
owner's available GitHub contact method. Do not post sensitive personal details
in a public issue.
